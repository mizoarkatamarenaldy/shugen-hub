    Template Pesan WhatsApp

    Atur teks template pesan ke pelanggan. Placeholder bertanda {...} akan diganti otomatis dengan data pesanan.

    Daftar Placeholder Tersedia:
    • {nama_pelanggan} : Nama pelanggan pesanan
    • {id_pesanan} atau [ID Pesanan] : ID pesanan (contoh: SGN-261011-K7M4)
    • {game} : Nama game yang dipesan
    • {total} : Total bayar pesanan (contoh: Rp 150.000)
    • {progress} : Persentase progress joki (contoh: 50%)
    • [Nama Partner] : Nama partner / penjoki
    • [Nominal] : Jumlah bagi hasil partner (contoh: 50.000)

    Jika sebuah data kosong, placeholder akan diganti dengan teks kosong.

    1. Template Konfirmasi Disarankan untuk pesanan Menunggu Bayar
    2. Template Update Progress Disarankan untuk pesanan Diproses
    3. Template Selesai Disarankan untuk pesanan Selesai
    4. Template Konfirmasi Payout Untuk konfirmasi transfer bagi hasil ke partner
